# Ilkerkeklik01 Tap

## How do I install these formulae?

`brew install ilkerkeklik01/tap/<formula>`

Or `brew tap ilkerkeklik01/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "ilkerkeklik01/tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
